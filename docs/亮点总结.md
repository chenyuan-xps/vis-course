# 《可视化导论》课程网站 · 亮点总结

> 一句话定位：把「5 章 27 节」的静态讲义，改造成一条**可预测、可操作、可自测、可追踪**的学习路径。

## 一、改造前的问题

| 现象 | 后果 |
| --- | --- |
| 打开页面就等于「学过」 | 进度数字虚高，学生和教师都无法判断真实掌握程度 |
| 讲解、代码、演示三块各自为政 | 学生看完演示不知道「该看什么」，教师上课要反复口头补充 |
| 搜索只匹配标题、收藏只能收藏 | 找不到正文里的概念；收藏夹变成摆设，无法形成学习计划 |

## 二、六个核心亮点

### 1. 每节都是完整的教学闭环

固定七步：**学习目标 → 知识链接 → 先预测 → 交互演示 → 小结 → 自测 → 章末复习**。

- 每节 2–3 条可检验的学习目标，配「未开始 / 学习中 / 已完成」状态徽章。
- 演示之前先让学生选一个预测，答完才揭示结果与解释，把「看动画」变成「做判断」。
- 自测 1–3 题，答后立即给解析，解析可一键跳回对应讲解段落；答错可重试。
- 每章末尾有复习页：关键概念 / 应该会做 / 常见错误，并链接回各节自测。

### 2. 进度语义被真正修正

- 打开小节只记为**学习中**，不再自动算完成。
- **已完成**只能由学生点「标记本节已完成」，或自测全部答对触发，且可撤销。
- 状态只升不降，刷新、换标签页、重复访问都不会把「已完成」打回原形。
- 首页出现「继续上次学习」卡片，显示章节、小节、完成度，一键回到上次离开的位置。

### 3. 搜索真的在搜课程内容

- 首次搜索时抓取各章正文，索引**讲解、代码说明、学习目标、小结、自测**，不只标题。
- 结果带所属章节、小节与匹配摘要，支持「本章 / 全课程」切换。
- 键盘完整可用：`Ctrl/Cmd + K` 或 `/` 打开，`↑ ↓` 选择，`Enter` 打开，`Esc` 关闭，焦点循环、背景滚动锁定、关闭后焦点归位。
- 输入框、下拉框、演示控件内不抢方向键，避免和页面切换冲突。

### 4. 收藏升级为「我的学习清单」

- 收藏的小节进入清单，可按章节筛选、直接跳转、一键移除。
- 学习档案页汇总「已完成 / 学习中 / 总小节」与完成度条。
- 学习记录可**导出 JSON 备份、导入恢复**；导入按状态优先级合并，不会用低状态覆盖高状态。

### 5. 演示区从「能跑」升级为「能讲清楚」

- 统一的「重置演示」按钮，重置会重新挂载演示，不用刷新整页。
- 每个按钮、滑块、下拉框都有**逐项说明**：它改哪个变量、你会看到什么变化。
- 关键小节增加「错误方案 → 改进方案 → 为什么」三行对照，例如用发散色带画有序数据、用彩虹色相编码数值、拉伸坐标轴夸大趋势。
- 重要案例标注数据来源与限制：合成数据的用途、不能用于真实人口分析等。
- 断网导致 D3 未加载时，演示区显示明确提示，并给出本地引入 D3 的替代方案，而不是留一块空白。

### 6. 设计系统与工程结构同时收敛

- **全站统一蓝—青—灰主题**：章节侧栏、卡片强调色、代码高亮不再各章一色；暗色模式单独一套高对比配色。
- **无障碍**：知识地图与统计图的节点可键盘聚焦、`Enter` 打开，并提供等价的 HTML 列表与数据表；正文、辅助文字、轴标签按 WCAG AA 调整对比度。
- **单一数据源**：[`course-config.js`](../assets/course-config.js) 集中维护章节、目标、预测、控制说明、对照、自测、复习与双语文案；页面不再手写统计数字。
- **可维护性**：学习记录集中在 [`course-store.js`](../assets/course-store.js)，检索在 [`course-search.js`](../assets/course-search.js)，组件样式集中在 [`enhance.css`](../assets/enhance.css)；清掉了开屏动画、失效卡片状态、按章变色等历史规则。

| 外部依赖 | 仅 D3.js v7（CDN，可离线替换） |

## 四、适用场景

- **课堂讲解**：左侧选小节，顶部切「讲解 / 代码 / 演示」，讲完立刻做预测和自测。
- **学生自学**：按目标清单推进，靠三态进度和清单掌握自己的节奏。
- **教师复用**：改一节内容只需改配置，章节名、小节数、双语标题与目标自动同步。
- **局域网授课**：`python -m http.server` 一条命令，学生同一 WiFi 即可访问。

## 五、已验证

- 全部 JS 通过语法检查；27 节控件、9 节对照、双语切换、搜索、进度、清单、导入导出均通过 jsdom 断言。
- 真实浏览器（Edge）浅色 / 深色实测：目标、预测、演示、对照、自测无重叠与裁切，控制台无报错。
- 关键文字对比度：正文 ≥ 7:1，辅助文字 ≥ 4.5:1，暗色卡片编号 7–8:1。
