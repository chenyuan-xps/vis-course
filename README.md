# 《可视化导论》课程网站

零依赖的静态课程网站：纯 HTML + CSS + ES modules，图表用 D3.js v7（CDN），无需构建、无需安装。

## 📚 页面结构

| 页面 | 内容 |
| --- | --- |
| `index.html` | 门户首页：知识地图、继续上次学习、课程搜索 |
| `stats.html` | 课程数据一览（小节数 / 知识点数，含文字版数据表） |
| `chapters.html` | 章节卡片墙 + 学习档案（进度 / 清单 / 导入导出） |
| `howto.html` | 使用方式 |
| `about.html` | 关于本课程 |
| `lesson-01/` ~ `lesson-05/` | 五章正文，每章含 讲解 / 关键代码 / 演示 三个 tab |

## ▶️ 本地运行

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

不要直接双击 `index.html`：课程页通过 `fetch` 读取各章正文建立搜索索引，`file://` 下浏览器会拦截该请求。用本地服务器打开即可正常使用。

## ✨ 学习闭环

每个小节按固定结构展开，学生每一步都知道“要学什么、为什么学、学完能做什么”：

1. **学习目标**：2–3 条可检验的目标，附「未开始 / 学习中 / 已完成」状态。
2. **知识链接**：相关小节可直接跳转，例如测量尺度 → 视觉通道 → 颜色专题。
3. **先预测，再看结果**：演示前先选一个预测，再操作图表对照。
4. **交互演示**：统一提供「重置演示」，并说明每个控制项改变的是哪个变量。
5. **小结**：适用场景、需要谨慎的情况，以及「错误方案 → 改进方案 → 为什么」三行对照。
6. **自测**：1–3 道题，答后立即给出解析，可回到对应讲解段落。
7. **章末复习**：关键概念 / 应该会做 / 常见错误，并链接回各节自测。

演示区的说明文字下方还有一张「控制项说明」表：每个按钮、滑块、下拉框单独列出，说明它改变的变量与你能观察到什么。

### 进度与记录

- 打开小节只记为「学习中」，不再等同于「已完成」。
- 「已完成」由学生点击「标记本节已完成」或自测全部答对触发，可撤销。
- 首页显示「继续上次学习」，自动定位到上次离开的小节。
- 收藏小节会进入「我的学习清单」，可按章节筛选、跳转或移除。
- 学习记录保存在 `localStorage`，可在 `chapters.html` 导出 / 导入 JSON 备份。

### 搜索

门户与章节页均支持全文检索：索引讲解正文、代码说明、学习目标、小结与自测，结果带所属章节与匹配摘要。章节页默认搜索本章，可切换到全课程。

快捷键：`Ctrl / Cmd + K` 或 `/` 打开搜索；`↑ ↓` 选择、`Enter` 打开、`Esc` 关闭；`← / →` 切换小节；`?` 查看说明。焦点在输入框、下拉框或演示控件内时，方向键不会被页面抢走。

## ✨ 其他特性

- **亮 / 暗主题**：右上角切换，`localStorage` 持久化，未选择时跟随系统
- **中英双语**：导航栏「中 / EN」切换，正文双 DOM 同步；新增动态文案统一进入 `assets/course-config.js` 的双语文案表
- **统一主题色**：全站（含章节侧栏、卡片强调色、代码高亮）使用一套蓝—青—灰配色，不再按章变色
- **零视频、零重资源**：所有插图与地图均为 SVG
- **无障碍**：知识地图与统计图的节点可通过键盘聚焦、`Enter` 打开，并提供等价的 HTML 列表 / 表格；正文、辅助文字与代码注释按 WCAG AA 调整过对比度

## 🗂️ 课程数据源

章节、小节、学习目标、预测、控制项说明、小结、错误/改进对照、自测与复习要点集中在 [`assets/course-config.js`](assets/course-config.js)。章节名、小节数、双语标题与路径都从这里读取，页面里不再单独维护统计数字。

`controls` 是 `[控件名, 作用]` 的数组，`compare` 是 `{ bad, good, why }`，两者都是可选字段；新增小节时按需补，不必为静态演示硬造控件。

学习记录读写集中在 [`assets/course-store.js`](assets/course-store.js)；全文索引在 [`assets/course-search.js`](assets/course-search.js)。

## ⚠️ 外部依赖与离线

D3.js 通过 CDN 加载。断网时依赖 D3 的演示不会初始化，演示区会显示「演示脚本未加载」的提示。解决方式：

1. 连接网络后刷新；或
2. 下载 `d3.v7.min.js` 放到 `assets/`，把各章 `index.html` 中的 CDN 地址改为本地路径。

课程讲解、目标、自测、搜索与进度记录不依赖 D3，断网仍可使用。

## 🎯 设计原则

1. **案例为中心**：每个理论点都嵌入实践案例
2. **代码可运行**：⭐ 关键点均配有可点击运行的演示
3. **讲解 ⇄ 代码 ⇄ 演示**：无缝切换，适合课堂“一边讲、一边演”
4. **零安装**：学生浏览器打开即用
