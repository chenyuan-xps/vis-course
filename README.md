# 《可视化导论》课程网站

零依赖的静态课程网站：纯 HTML + CSS + ES modules，图表用 D3.js v7（CDN），无需构建、无需安装。

## 📚 页面结构

| 页面 | 内容 |
| --- | --- |
| `index.html` | 知识地图（首次访问播放开屏动画） |
| `stats.html` | 课程数据一览（小节数 / 知识点数） |
| `chapters.html` | 章节卡片墙 |
| `howto.html` | 使用方式 |
| `about.html` | 关于本课程 |
| `lesson-01/` ~ `lesson-05/` | 五章正文，每章含 讲解 / 关键代码 / 演示 三个 tab |

## ▶️ 本地运行

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

## ✨ 特性

- **亮 / 暗主题**：右上角切换，`localStorage` 持久化，未选择时跟随系统
- **中英双语**：导航栏「中 / EN」切换，正文双 DOM 同步
- **零视频、零重资源**：所有插图与地图均为 SVG，仓库体积约 3 MB
- **章节主题色**：五章各有一套强调色，贯穿章头、步进器与正文组件

## 🎯 设计原则

1. **案例为中心**：每个理论点都嵌入实践案例
2. **代码可运行**：⭐ 关键点均配有可点击运行的演示
3. **讲解 ⇄ 代码 ⇄ 演示**：无缝切换，适合课堂"一边讲、一边演"
4. **零安装**：学生浏览器打开即用
